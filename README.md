# How AI Agents Work

Interactive field guides for product managers, built around one running example: a research-assistant agent.

| Page | Live link |
|---|---|
| **How AI agents work**: ideation, design, build, test and ship, with a step-by-step simulated agent demo, quizzes and a cheat sheet | https://lalwalataukir.github.io/how-ai-agents-work/ |
| **LangChain, LangGraph & Langfuse**: what each tool does and how they fit together, with a clickable simulated graph run and a Langfuse-style trace | https://lalwalataukir.github.io/how-ai-agents-work/langchain-langgraph-langfuse.html |

Everything in the demos is a scripted simulation. No AI model, search engine, framework or tracing service is contacted, and the example addresses are made up. These pages are independent explainers and aren't affiliated with LangChain, LangGraph, LangSmith or Langfuse.

The HTML files here are generated from the source pages by running `node serve.js --build`.
