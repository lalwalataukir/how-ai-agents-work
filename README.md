# How AI Agents Work

An interactive field guide for product managers. It follows one example, a research-assistant agent, through ideation, design, build, test and ship, and includes a step-by-step simulated agent demo, quizzes and a cheat sheet.

**Live site:** https://lalwalataukir.github.io/how-ai-agents-work/

Everything in the demo is a scripted simulation. No AI model, search engine or website is contacted, and the example addresses are made up.

`index.html` is generated from `how-ai-agents-work.html` by running `node serve.js --build`.
