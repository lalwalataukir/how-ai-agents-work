# NextModule

The bar at the end of a module that sends the reader to the next one in reading order.

## Use
- Last block before the footer, `space-40` above it.
- Eyebrow text is "Next · Module N"; the link is the module's full title followed by " →".
- On the last module, point to the Reference page instead.

## Source
`how-ai-agents-work.html` `.next-module`. Static rendition of the guides' markup, styled by `components/bundle.css`.
