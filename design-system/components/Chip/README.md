# Chip

Pill buttons that fill an input with a suggested value, such as a sample question in the live demo.

## Use
- Inside `.chips`, optionally led by a muted `.lbl` ("Try:").
- `bg` fill with a `line` border; hover turns border and text `accent`.
- Chips are actions. For a static label use Tag or LoopPhase instead.

## Source
`how-ai-agents-work.html` `.chips`, `.chip`. Static rendition of the guides' markup, styled by `components/bundle.css`.
