# Takeaway

The one-sentence conclusion of a section, set in the display face under a 2px `ink` rule.

## Use
- `.takeaway` pairs a mono key ("Takeaway") with one display sentence. One per section, at its end.
- `.tips` / `.tip` is the multi-item version used on the home page's "How to use these guides": a bold display line and a muted sentence.
- The rule is `ink`, not accent: it reads as a printed manual's rule, not a highlight.

## Source
`metrics.html` `.takeaway`, `index.html` `.tip`. Static rendition of the guides' markup, styled by `components/bundle.css`.
