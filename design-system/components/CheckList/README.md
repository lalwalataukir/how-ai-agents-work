# CheckList

A list of questions to ask, each marked with a small accent-outlined square holding a letter or number.

## Use
- `ul.check-list` > `li` > `span.q` + text. The marker is mono, 24px, `radius-sm`, 1.5px `accent` border.
- Use for questions a PM should ask the team, or launch checks. Write each item as a question or an imperative.

## Source
`how-ai-agents-work.html` `.check-list`. Static rendition of the guides' markup, styled by `components/bundle.css`.
