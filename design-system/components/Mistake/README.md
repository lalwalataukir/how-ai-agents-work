# Mistake

A numbered common mistake with what it looks like and the fix.

## Use
- Inside `.mistakes` (auto-fit, min 300px).
- The numeral is display 2rem in `bad`. Below it an `h4`, then a `dl` with the terms "What it looks like" and "Fix".
- Number them only because the module ranks them; keep the list to the real mistakes.

## Source
`how-ai-agents-work.html` `.mistake`. Static rendition of the guides' markup, styled by `components/bundle.css`.
