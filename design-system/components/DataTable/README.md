# DataTable

A comparison table inside a scrollable, bordered wrapper.

## Use
- Always wrap in `.tablewrap`, which scrolls sideways on phones; the table keeps a 620px minimum.
- Headers are display-face on `surface-2`. The first column is bold: it names the row.
- Mark a positive cell with `.yes` (`final`), and write the word ("Yes"), never just a tick.
