# Tag

A small uppercase mono label that classifies a box or card: a level, a kind, "Example".

## Use
- `.tag` is neutral (`surface-2` fill, `muted` text). `.tag.accent` (accent on `accent-soft`) marks the one tag in a group that matters most.
- One or two words, set in uppercase by the class; write them in sentence case in the markup.
- Sits at the top of a Box, left-aligned (`justify-self:start`).
