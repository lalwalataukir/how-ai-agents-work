# SimBanner

The full-width notice at the top of every demo that says it is a scripted simulation.

## Use
- Required on every demo console, first row. `act-soft` fill; the lead word "Simulation." is bold `act`.
- Say plainly what is fake: the model, the searches, the pages, the addresses.

## Source
`how-ai-agents-work.html` `.sim-banner`. Static rendition of the guides' markup, styled by `components/bundle.css`.
