# StatusBar

A mono line of run meta under the demo controls: step, tokens, cost, time.

## Use
- Values in `<b>` (ink), labels in `muted`. Tabular figures so numbers don't jitter as they change.
- Use real units: tokens, $ to three decimals, seconds.

## Source
`how-ai-agents-work.html` `.statusbar`. Static rendition of the guides' markup, styled by `components/bundle.css`.
