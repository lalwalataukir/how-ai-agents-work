# Callout

A short aside that names why something matters, set on `accent-soft`.

## Use
- Starts with a bold lead-in that ends in a full stop ("Plain definition.", "Why this matters.", "You've seen this pattern before."); the lead-in is `accent`.
- One to three sentences. At most one per concept block. Max width 76ch.

## Source
`how-ai-agents-work.html` `.callout`. Static rendition of the guides' markup, styled by `components/bundle.css`.
