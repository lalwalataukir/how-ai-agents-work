# MetricTile

A number with its label, used in calculators and cost readouts.

## Use
- `.metric` on `surface-2`, `radius-md`. Value in mono 1.25rem, tabular figures; label in muted .82rem below.
- `.metric.warn` turns the value `bad` when it crosses a limit; say why in the label or nearby text.
- Two-up in `.calc-out`.

## Source
`how-ai-agents-work.html` `.metric`. Static rendition of the guides' markup, styled by `components/bundle.css`.
