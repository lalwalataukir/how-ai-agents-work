The brief

The ticket you're picking up

Every criterion below has a check in the starter's tests, or a number your eval measures.

P4 · research-teamEstimate: 6 hours · Labels: python, claude-api, agents, langfuse

As a busy reader, I want a short report on a topic with every fact cited, so that I can learn it quickly and check anything I doubt.

Acceptance criteria

  • A planner splits the topic into 3 to 5 questions
  • Workers research the questions at the same time, each within a budget of 6 model calls and $0.01
  • Every paragraph cites numbered sources, and the sources are only pages a worker actually read
  • A critic checks the report, with code checking the citations, and the writer revises once if needed
  • Each run is one trace in Langfuse, with every agent inside it
  • An eval of 5 topics measures citations, coverage and faithfulness, and a comparison shows what each role's model costs

When a team beats one agent

A team costs more tokens than one agent, so it has to earn them. It does when the work splits into parts that don't depend on each other (four questions researched at once, each in its own small context), or when a fresh view catches what the author missed (a critic). If neither is true, E7's single agent is cheaper and simpler.

What you practise

  • An in plain Python: plan, , write, check
  • Budgets per agent, and costs per role
  • Threads, a lock, and traces that still nest
  • An eval and a model choice for the whole team (E8, E11)

Architecture

How the parts fit

team.py holds the four roles and run; wiki.py is E5's Wikipedia tools; evals.py and compare_roles.py measure it. The milestone that builds each part is in brackets, and dashed boxes can repeat.

  1. Planplan: 3 to 5 questions, as structured output (1)
  2. Research in parallelresearch_all: one worker per question, each with a budget (2)
  3. Number the sourcesnumber_sources: every page read, once (3)
  4. Writewrite: a report citing [1], [2]… (3)
  5. Critique, revise oncecitation_problems and critique (4)
  6. Measurea trace per run, an eval, and a model per role (5, 6)

Each agent sees only what it needs: workers see one question, the writer sees the findings, the critic sees the findings and the report. Code passes the work between them, numbers the sources, checks the citations and decides when to stop.

def plan(topic, costs):    """The sub-questions for a topic: at least 2, at most MAX_QUESTIONS, no repeats."""    response = client.messages.parse(        model=ROLES["planner"], max_tokens=2000, system=PLANNER, output_config={"effort": "low"},        messages=[{"role": "user", "content": f"<topic>{topic}</topic>"}], output_format=Plan,    )    costs.add("planner", response.usage)    questions = []    for question in response.parsed_output.questions:        if question.strip() and question.strip().lower() not in {q.lower() for q in questions}:            questions.append(question.strip())    if len(questions) < 2:        raise RuntimeError(f"The plan has {len(questions)} question(s); a report needs at least 2.")    return questions[:MAX_QUESTIONS]

2 · Milestone 2 of 6

Workers, in parallel

One worker per question, all at once, each with its own budget. The pages they read are recorded by code, so the report can only cite what was really read.

About 1¼ hoursUses E5, E7

Each worker is E5's research loop on one question, with a small context of its own: one question's pages, not everyone's. Running them at once is the that makes a team fast: the time is the slowest worker, not the sum. Python threads suit this, because the workers spend their time waiting for the network.

Two things change when code runs in threads. Shared totals need a lock, or two workers adding at the same moment lose one addition: a . Costs has one already. And each thread needs a copy of the current context, so its trace lands inside the run's (milestone 5): that's .

What you write

  • research(question, costs): one worker. Returns a Finding.
  • research_all(questions, costs): every worker at once, in the questions' order.

Run tools with wiki.run_tool, send a ValueError back as an error, and add each new page from read_page to finding.sources.

def research(question, costs):    """One worker: E5's tool loop on one question, within its own budget of calls and dollars.    The pages it reads are recorded by code, so the report can only cite what was really read."""    finding, spent = Finding(question), 0.0    messages = [{"role": "user", "content": question}]    while True:        if finding.calls >= MAX_WORKER_CALLS or spent >= MAX_WORKER_COST:  # the budget, checked before each call            finding.stopped = "budget"            break        response = client.messages.create(model=ROLES["worker"], max_tokens=2000, system=WORKER, tools=wiki.TOOLS,                                          messages=messages, output_config={"effort": "low"})        spent += costs.add("worker", response.usage)  # this worker's own spending, for its budget        finding.calls += 1        messages.append({"role": "assistant", "content": response.content})        if response.stop_reason != "tool_use":            finding.answer = "".join(block.text for block in response.content if block.type == "text")            break        results = []        for block in response.content:            if block.type != "tool_use":                continue            try:                result, failed = wiki.run_tool(block.name, block.input), False                if block.name == "read_page" and result["title"] not in {s["title"] for s in finding.sources}:                    finding.sources.append(result)                text = wiki.as_text(result)            except ValueError as error:                text, failed = str(error), True            results.append({"type": "tool_result", "tool_use_id": block.id, "content": text, "is_error": failed})        messages.append({"role": "user", "content": results})    return finding
team.py
def research_all(questions, costs):    """Research every question at once, WORKERS at a time. One worker failing doesn't stop the others."""    with ThreadPoolExecutor(max_workers=WORKERS) as pool:        # each worker runs in a copy of this context, so its trace nests under this run (milestone 5)        futures = [pool.submit(contextvars.copy_context().run, research, question, costs) for question in questions]    findings = []    for question, future in zip(questions, futures):        try:            findings.append(future.result())        except Exception as error:  # a crash in one worker becomes a gap in the report, not a failed run            findings.append(Finding(question, stopped=f"failed: {type(error).__name__}: {error}"))    return findings

The writer

Turn the findings into a short report where every paragraph cites numbered sources, and the list of sources is built by code.

About 45 minutesUses E4, PM 8

The workers cite pages by title; a report reads better with numbers. Code numbers the pages the workers actually read, the writer cites those numbers, and code writes the list of sources at the end. The writer never types a link, so every link in the report is a page someone read. The writer sees only the findings and the sources: that context is the whole truth it may use.

def number_sources(findings):    """Every page the workers read, once each, numbered from 1 in the order they were found."""    sources = []    for finding in findings:        for source in finding.sources:            if source["title"] not in [s["title"] for s in sources]:                sources.append(source)    return sources

def write(topic, findings, sources, costs, issues=()):    """Draft the report, or revise it when issues are given, and add the numbered list of sources."""    numbered = "\n".join(f"[{n}] {s['title']}: {s['summary']}" for n, s in enumerate(sources, 1))    notes = "\n\n".join(f"Q: {f.question}\nA: {f.answer or '(nothing found: ' + (f.stopped or 'no answer') + ')'}" for f in findings)    prompt = f"<topic>{topic}</topic>\n\n<findings>\n{notes}\n</findings>\n\n<sources>\n{numbered}\n</sources>"    if issues:        prompt += "\n\nA reviewer found these problems in your last draft. Write it again without them:\n" + "\n".join(f"- {i}" for i in issues)    response = client.messages.create(model=ROLES["writer"], max_tokens=4000, system=WRITER,                                      messages=[{"role": "user", "content": prompt}])    costs.add("writer", response.usage)    body = "".join(block.text for block in response.content if block.type == "text").strip()    return body + "\n\n## Sources\n\n" + "\n".join(f"{n}. [{s['title']}]({s['url']})" for n, s in enumerate(sources, 1)) + "\n"

4 · Milestone 4 of 6

The critic, and the whole run

A second agent checks the report against the findings, code checks the citations, and the writer revises once. Then put the whole team together.

About 1 hourUses E8, E7

A works because it starts fresh: it didn't write the report, so it has nothing to defend, and its instructions are only about finding problems. Code checks what code can (every [n] is a real source, every paragraph cites one), so the critic model spends its attention on what needs judgement. One revision is enough: a second round costs as much again and rarely finds more.

What you write

  • citation_problems(report, count): what code can check.
  • critique(report, findings, sources, costs): code first, then the critic model.
  • run(topic): the whole team, in order. Returns a Result.

    Write citation_problems

    Use only the body (body_of cuts off the sources). One problem for each cited number outside 1 to count, and one for each paragraph, skipping headings, with no [n] in it. Make each one specific enough to fix.

    Write critique

team.py
def citation_problems(report, count):    """What code can check: every citation number exists, and every paragraph cites something."""    problems = []    for number in sorted({int(n) for n in re.findall(r"\[(\d+)\]", body_of(report))}):        if not 1 <= number <= count:            problems.append(f"[{number}] is cited, but there are only {count} sources.")    for paragraph in body_of(report).split("\n\n"):        if paragraph.strip() and not paragraph.lstrip().startswith("#") and not re.search(r"\[\d+\]", paragraph):            problems.append(f"This paragraph has no citation: {paragraph.strip()[:60]}...")    return problems
team.py
def critique(report, findings, sources, costs):    """Code checks first, then the critic model. Returns the list of issues; empty means approved."""    issues = citation_problems(report, len(sources))    notes = "\n\n".join(f"Q: {f.question}\nA: {f.answer}" for f in findings)    response = client.messages.parse(        model=ROLES["critic"], max_tokens=2000, system=CRITIC, output_format=Critique,        messages=[{"role": "user", "content": f"<findings>\n{notes}\n</findings>\n\n<report>\n{report}\n</report>"}],    )    costs.add("critic", response.usage)    return issues + ([] if response.parsed_output.approved else response.parsed_output.issues)
team.py
def run(topic):    """The whole team: plan, research in parallel, write, critique, and revise once if needed."""    start, costs = time.perf_counter(), Costs()    questions = plan(topic, costs)    findings = research_all(questions, costs)    sources = number_sources(findings)    report = write(topic, findings, sources, costs)    issues = critique(report, findings, sources, costs)    if issues:  # one revision: a second critique would cost more than it usually finds        report = write(topic, findings, sources, costs, issues)    return Result(report, questions, findings, sources, issues, bool(issues), costs, round(time.perf_counter() - start, 1))

def cited_share(report):    """The share of the body's paragraphs (not headings) that cite at least one source."""    paragraphs = [p for p in team.body_of(report).split("\n\n") if p.strip() and not p.lstrip().startswith("#")]    return sum(bool(re.search(r"\[\d+\]", p)) for p in paragraphs) / len(paragraphs) if paragraphs else 0.0

def mentions(report, terms):    """The share of terms the report mentions. "sunshield|sun shield" means either will do."""    text = report.lower()    return sum(any(word.lower() in text for word in term.split("|")) for term in terms) / len(terms)

def run_topic(case):    """One topic: run the team, grade the report, and score the trace in Langfuse."""    with propagate_attributes(tags=["eval"], metadata={"topic": case["topic"]}):  # find eval runs in Langfuse        result = team.run(case["topic"])        cited, mentioned = cited_share(result.report), mentions(result.report, case["must_mention"])        verdict, judge_cost = judge(result)        passed = cited >= MIN_CITED and mentioned >= MIN_MENTIONS and verdict.passed        team.langfuse.score_current_trace(name="passed", value=float(passed), comment=verdict.reason)    return {"topic": case["topic"], "passed": passed, "cited": cited, "mentions": mentioned, "judge": verdict.passed,            "reason": verdict.reason, "cost": result.costs.total() + judge_cost, "seconds": result.seconds}

def compare(limit=None):    """Run the eval with each choice of roles. Returns {choice: (passed, reports, cost per report, seconds per report)}."""    saved, table = dict(team.ROLES), {}    try:        for name, roles in CHOICES.items():            team.ROLES.update(roles)            rows = evals.main(limit, quiet=True)            table[name] = (sum(r["passed"] for r in rows), len(rows), sum(r["cost"] for r in rows) / len(rows),                           sum(r["seconds"] for r in rows) / len(rows))    finally:        team.ROLES.update(saved)  # put the real choice back, whatever happened    return table
