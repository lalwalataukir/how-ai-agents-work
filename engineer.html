Checklist

Before you start

A laptop you can install software on

Mac or Windows, with admin rights. Any laptop from the last five years is fine. Linux works too: follow the Mac commands.

A GitHub account

Free, at github.com. Your project lives there, and at the end it's your portfolio.

An API key, from E3 on

You'll create one in E3. Set a monthly spending limit when you do: $10 is plenty, and all the labs together cost under $5.

About 5 hours a week

At that pace the track takes 9 to 10 weeks. Short, regular sessions beat one long weekend: you'll remember more between modules.

No coding experience needed

E1 starts from opening a terminal. If you can follow a recipe and read an error message carefully, you can do this.

The PM modules are optional

Each E-module links to the PM module it builds on. Module 1 is the best primer if agents are new to you.

Format

How each module works

  1. What you'll build: the result of the lab, up front.
  2. Concepts, with tap-to-define terms and links to the PM modules.
  3. A demo in the browser that needs no setup or API key, so you see the idea working before you code it.
  4. A lab on your laptop: numbered steps, code with a Copy button, the output you should see after each step, and an "If it breaks" box for the usual errors.
  5. Done when: a short checklist. Tick everything and the module is marked done here.
  6. Three quizzes, a cheat sheet and three common mistakes, like the PM modules.

The guided projects work differently: a starter to download, milestones with a checker that tells you when each part works, and hints that end in the solution.

Stuck? Every lab's finished code is in the labs folder on GitHub, tested on every change. Compare it with yours, line by line, before reaching for the answer.

Outcome

What you'll be able to do

These are the skills AI engineering job descriptions ask for, and the evidence for each one will be in your repo.

Build

  • Write and debug Python, and work in a terminal with git
  • Call LLM APIs, get structured output, and handle errors and retries
  • Give models tools, and build agents with plain code or LangGraph
  • Answer questions from documents with retrieval (RAG)

Ship

  • Trace runs, write evals and gate changes in CI
  • Deploy an AI app with sensible limits on cost and rate
  • Defend against prompt injection and data leaks
  • Choose a model with evidence: cost, speed and quality

Your portfolio at the end

A public GitHub repo with a clear README, evals that run on every push, a live URL, and a two-minute demo video. Plus the PM judgement from the other modules: you'll be able to explain why it's built the way it is.
