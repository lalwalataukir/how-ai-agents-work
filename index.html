Agent Field Guides

Interactive guides for product managers

Understand AI agents well enough to make good product calls

Ten modules, written for PMs rather than engineers. Start with how agents work and the tools at a glance, go deeper on each tool, learn what to measure in production, how to launch, how to manage what the model sees, how to keep agents secure, and how to run evals you can trust. Modules 1 to 5 and 7 to 10 follow the same example: a research assistant that takes a question, searches the web, reads the results and writes a short report. Module 6 takes those ideas into a regulated setting, a wealth assistant for investors. Every module has a hands-on demo you can click through, and quizzes to check yourself. When you want to build agents yourself, the new AI engineer track starts from the terminal.

How to use these guides

Tap underlined terms

The first time a technical word appears, it has a dotted underline. Tap it for a one-sentence definition.

Break the demos

Each demo has failure modes you can trigger. Seeing how an agent goes wrong teaches more than watching it succeed.

Keep the cheat sheets

Each module ends with a one-page summary and the questions to ask your engineering team. Module 1 also has a one-page agent spec template to download.

All demos are scripted simulations. No AI model, search engine, framework or tracing service is contacted, and the example web addresses are made up. Prices and timings are illustrative.
