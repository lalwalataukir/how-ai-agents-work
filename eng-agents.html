Building agents: plan, act, remember, stop

An is E5's tool loop with four additions: a plan before it acts, memory between questions, stop conditions that end a bad run, and a person's approval before anything changes. This module builds all four into the research assistant, using your notes from E6 and Wikipedia from E5. Then you'll rebuild it in LangGraph, and share your notes with other apps over MCP.

A research agent that plans, uses your notes and Wikipedia, remembers the conversation, and asks before it saves:

        1 · The agent loop
        
    
        A loop that decides its own next step
        
    
        In a , your code fixes the steps: search, then summarise. In an agent, the model picks the next step each time round the loop, and decides when it's done. That's the plan, act, observe cycle from module 1, in your code.
        
  
        
  
        
    
        Build an agent when
        The steps can't be known in advance, the result is worth extra cost and time, the model is good at this kind of task, and mistakes can be caught before they matter.
        
    
        Stay with a workflow when
        You can write the steps down. "Retrieve, then answer" is E6's workflow, and it's cheaper and easier to test than an agent doing the same job.
        
  
        
  
        Your code still owns everything that matters: which tools exist, how many calls a run may make, what it may spend, and what needs a person's yes. The model only chooses among the options you give it.

        2 · Planning
        
    
        Plan before acting
        
    
        Before any tool runs, one small call asks for a  of 1 to 4 steps, as structured output. The plan goes into the loop's first message, and the system prompt lets the model change it when a tool shows it won't work.
        
  
        
  
        Planning with structured output (from the lab)
        class Plan(BaseModel):    steps: list[str] response = client.messages.parse(    model=MODEL, max_tokens=1000, system=PLANNER, output_config={"effort": "low"},    messages=memory + [{"role": "user", "content": question}], output_format=Plan,)response.parsed_output.steps   # ["Search the user's notes for late fees", "Answer with citations"]
        
  
        
    
        Intent you can read
        The plan shows what the agent means to do before it does it. A bad plan explains a bad run.
        
    
        Fewer wasted calls
        A run that follows a plan wanders less than one that decides every step from scratch.
        
    
        Cheap
        The planning call sees only the question and memory, not tools or pages: a few hundred tokens.
        
  
        

        



        
  
        
    
        3 · Memory and state
        
    
        What the agent keeps, and for how long
        
    
        The API remembers nothing between requests (E3). Everything an agent "knows" about this run, this conversation or last week is something your code chose to keep and send.
        
  
        
  
        
    
        
      
        KindLastsIn the labCost
        
      
        
        One questionThe state dict: calls, tokens, cost, tools used, calls already madeNone: it stays in your code
        
        
        Short-term One sessionThe memory list: earlier questions and answers, not the tool calls behind themSent with every request, so it grows
        
        
        Long-term memoryUntil deletedNotes saved by save_note, indexed into E6's database and found by search_notesOnly what retrieval brings back
        
              
    
        
  
        
  
        Memory is a design choice. The lab keeps answers and drops the tool calls and pages behind them: a follow-up still knows what "that" means, at a fraction of the tokens. Module 8 covers the other options, such as summarising old turns.
        

        



        
  
        
    
        4 · Stop conditions
        
    
        Every loop needs a way out
        
    
        A confused agent can loop for ever, and every lap costs money. The lab checks its  before every model call, not after.
        
  
        
  
        
    
        
      
        ConditionCatchesIn the lab
        
      
        
        The model answersThe normal endstop_reason isn't "tool_use"
        
        
        Call limitWandering and endless retriesMAX_CALLS = 10 per question, the plan included
        
        
        Cost limitA few huge pages or long answersMAX_COST = 0.02 dollars per question
        
        
        Repeat guardAsking for the same thing again and againAn identical call gets "You already made this exact call"
        
        
        Cut offAn answer longer than max_tokensThe answer is flagged "(Stopped early: max_tokens)"

        5 · Human approval
        
    
        A person says yes to anything that changes something
        
    
        Reading is safe to automate; writing, sending and deleting are not. Tools in NEEDS_APPROVAL run only after a person sees exactly what will happen and says yes. That's .
        
  
        
  
        
    
        Show the real action
        The approval shows the tool and its exact arguments, the note's real title and text, not the model's summary of them.
        
    
        No means no
        A refusal goes back as an error the model must respect: "The user said no. Don't try again."
        
    
        Offer less in risky places
        The tools list decides what a run may use, whatever the model asks for. E9's public web app gets the read-only tools only.
        
  
        
  
        Module 9 shows why this matters: an instruction hidden in a web page can ask your agent to do things. Approval and a short tool list mean a tricked agent can't act on it alone. E10 adds more defences in code.

          agent.py
          """E7 lab: the research assistant as an agent. It makes a plan, searches your notes andWikipedia, remembers the conversation, stops at its limits, and asks before it saves anything. Run it with:    uv run agent.py"""import jsonimport refrom datetime import datefrom pathlib import Path import anthropicfrom dotenv import load_dotenvfrom pydantic import BaseModel from rag import index_file, search  # E6: your notesfrom research_bot import TOOLS as WIKI_TOOLS, run_tool as run_wiki_tool  # E5: Wikipedia load_dotenv() MODEL = "claude-haiku-5-5"PRICE_IN, PRICE_OUT = 0.10, 0.50  # dollars per million tokens, for this modelMAX_CALLS = 10   # stop condition: most model calls for one questionMAX_COST = 0.02  # stop condition: most dollars for one questionNOTES = Path(__file__).parent / "notes"  # save_note writes Markdown files hereSYSTEM = (    "You are a research assistant. Use the tools to search the user's notes and Wikipedia, and follow "    "the plan you're given, changing it if a tool shows it won't work. Cite every fact: [Page title] "    "for Wikipedia, [file, page N] for the user's notes. Save a note only when the user asks you to. "    "If you can't find the answer, say so. Answer in at most 200 words.")PLANNER = (    "You plan the work of a research assistant. Its tools: search_notes (the user's own notes and PDFs), "    "search_wikipedia and read_page (Wikipedia), and save_note (only when the user asks to save something). "    "Write a plan of 1 to 4 short steps for the latest request. Don't answer it.") TOOLS = WIKI_TOOLS + [    {        "name": "search_notes",        "description": "Search the user's own notes and PDFs. Returns up to 4 passages, each with its file "                       "and page. Use it first for anything the user may have notes on.",        "input_schema": {            "type": "object",            "properties": {"query": {"type": "string", "description": "What to look for, in plain words"}},            "required": ["query"],            "additionalProperties": False,        },        "strict": True,    },    {        "name": "save_note",        "description": "Save a note for the user as a Markdown file. Only use it when the user asks to save "                       "something. The user approves every save.",        "input_schema": {            "type": "object",            "properties": {                "title": {"type": "string", "description": "A short title"},                "text": {"type": "string", "description": "The note, with its citations"},            },            "required": ["title", "text"],            "additionalProperties": False,        },        "strict": True,    },]ALL_TOOLS = [tool["name"] for tool in TOOLS]NEEDS_APPROVAL = {"save_note"}  # tools that change something: a person says yes first client = anthropic.Anthropic()  class Plan(BaseModel):    steps: list[str]  def make_plan(question, memory):    """Ask for a short plan before any tool runs. Returns the steps and the call's token usage."""    response = client.messages.parse(        model=MODEL, max_tokens=1000, system=PLANNER, output_config={"effort": "low"},        messages=memory + [{"role": "user", "content": question}], output_format=Plan,    )    return response.parsed_output.steps, response.usage  def save_note(title, text):    """Write a Markdown note, and add it to your notes so search_notes can find it later."""    NOTES.mkdir(exist_ok=True)    slug = re.sub(r"[^a-z0-9]+", "-", title.lower()).strip("-")[:50] or "note"    path = NOTES / f"{date.today()}-{slug}.md"    path.write_text(f"# {title}\n\n{text}\n", encoding="utf-8")    index_file(path, NOTES)    return {"saved": path.name}  def ask_to_approve(name, args):    """Human approval: show what the agent wants to do and wait for a yes."""    print(f"\n  The agent wants to run {name}:")    for key, value in args.items():        print(f"    {key}: {value}")    return input("  Allow it? [y/N] ").strip().lower() == "y"  def run_tool(name, args, approve):    """Run one tool call. Returns the text to send back, and whether it failed."""    if name in ("search_wikipedia", "read_page"):        return run_wiki_tool(name, args)  # E5's code, with its error handling    if name in NEEDS_APPROVAL and not approve(name, args):        return "The user said no. Don't try again; tell them it wasn't saved.", True    if name == "search_notes":        return json.dumps(search(args["query"]) or "No notes matched."), False    if name == "save_note":        return json.dumps(save_note(args["title"], args["text"])), False    return f"There is no tool called {name}.", True  def add_usage(state, usage):    state["calls"] += 1    state["tokens_in"] += usage.input_tokens    state["tokens_out"] += usage.output_tokens    state["cost"] = (state["tokens_in"] * PRICE_IN + state["tokens_out"] * PRICE_OUT) / 1_000_000  def steps(question, memory, tools=ALL_TOOLS, approve=ask_to_approve):    """Run the agent on one question, yielding an event for each thing it does:    a plan, each tool call, and finally "done" with the answer and what it cost."""    state = {"calls": 0, "tokens_in": 0, "tokens_out": 0, "cost": 0.0, "tools": []}  # this run's state    plan, usage = make_plan(question, memory)    add_usage(state, usage)    yield {"type": "plan", "steps": plan}     numbered = "\n".join(f"{n}. {step}" for n, step in enumerate(plan, 1))    messages = memory + [{"role": "user", "content": f"{question}\n\n<plan>\n{numbered}\n</plan>"}]    offered = [tool for tool in TOOLS if tool["name"] in tools]    seen = set()  # tool calls already made, to catch a loop asking for the same thing    while True:        if state["calls"] >= MAX_CALLS or state["cost"] >= MAX_COST:  # stop conditions, before every call            answer = f"Stopped: this question reached its limit of {MAX_CALLS} model calls or ${MAX_COST}."            break        response = client.messages.create(            model=MODEL, max_tokens=4000, system=SYSTEM, tools=offered, messages=messages,        )        add_usage(state, response.usage)        messages.append({"role": "assistant", "content": response.content})        if response.stop_reason != "tool_use":  # the model answered            answer = "".join(block.text for block in response.content if block.type == "text")            if response.stop_reason != "end_turn":                answer += f"\n(Stopped early: {response.stop_reason})"            break         results = []        for block in response.content:            if block.type != "tool_use":                continue            yield {"type": "tool", "name": block.name, "input": block.input}            state["tools"].append(block.name)            key = block.name + json.dumps(block.input, sort_keys=True)            if block.name not in tools:  # only the tools offered for this run, whatever the model asks                text, failed = f"There is no tool called {block.name}.", True            elif key in seen:                text, failed = "You already made this exact call. Use its result above.", True            else:                seen.add(key)                text, failed = run_tool(block.name, block.input, approve)            results.append({"type": "tool_result", "tool_use_id": block.id, "content": text, "is_error": failed})        messages.append({"role": "user", "content": results})    yield {"type": "done", "answer": answer, **state}  def ask(question, memory):    """Run the agent in the terminal, then remember the question and answer for follow-ups."""    for event in steps(question, memory):        if event["type"] == "plan":            print("  plan: " + " | ".join(event["steps"]))        elif event["type"] == "tool":            print(f"  -> {event['name']}({json.dumps(event['input'])})")        elif event["type"] == "done":            print(f"  [{event['calls']} model calls, {event['tokens_in']} tokens in, "                  f"{event['tokens_out']} out, ${event['cost']:.5f}]\n")            print(event["answer"])            memory.append({"role": "user", "content": question})  # memory keeps the answers, not the tool calls            memory.append({"role": "assistant", "content": event["answer"]})  def main():    memory = []  # earlier questions and answers in this session    print("Ask a research question. Type quit to stop.")    while True:        question = input("\nYou: ").strip()        if question.lower() in ("quit", "exit"):            break        if not question:            continue        try:            ask(question, memory)        except anthropic.APIConnectionError:            print("Could not reach the API. Check your internet connection and try again.")        except anthropic.APIStatusError as error:  # a bad key, no credit, overloaded: after the SDK's retries            print(f"The API answered {error.status_code}: {error.message}")  if __name__ == "__main__":    main()
          • TOOLS reuses E5's two Wikipedia tools and adds search_notes (E6's search) and save_note.
          • make_plan asks for 1 to 4 steps as structured output (E4), before any tool runs.
          • run_tool asks a person before anything in NEEDS_APPROVAL, and save_note indexes the new note so search_notes can find it later.
          • steps is the loop. It checks the call and cost limits before every model call, refuses tools not offered for this run and repeated identical calls, and yields an event for each thing it does.
          • ask prints those events, then adds the question and answer to memory, so a follow-up like "save that" has something to refer to.
          yield makes steps a generator: it hands back one event at a time while it keeps running. The terminal prints them here; E8 records them for evals, and E9 streams them to a web page.

          agent_graph.py
          """E7 lab, part 2: the same agent as a LangGraph graph. LangGraph saves the state after everystep, so the graph can pause for your approval and pick up where it left off. Run it with:    uv run agent_graph.py          # chat with it    uv run agent_graph.py --draw   # print the graph as a Mermaid diagram"""import jsonimport operatorimport sysfrom typing import Annotated, TypedDict from langgraph.checkpoint.memory import InMemorySaverfrom langgraph.graph import END, START, StateGraphfrom langgraph.types import Command, interrupt import agent  # the model, prompts, tools and limits from agent.py  class State(TypedDict):    messages: Annotated[list, operator.add]  # each step's new messages are added to the list    calls: int      # model calls for the current question    cost: float     # dollars for the current question    approved: dict  # tool_use id -> the person's yes or no  def call_cost(usage):    return (usage.input_tokens * agent.PRICE_IN + usage.output_tokens * agent.PRICE_OUT) / 1_000_000  def plan(state):    """Make a plan for the newest question, and reset the per-question limits."""    steps, usage = agent.make_plan(state["messages"][-1]["content"], [])    print("  plan: " + " | ".join(steps))    numbered = "\n".join(f"{n}. {step}" for n, step in enumerate(steps, 1))    return {"messages": [{"role": "user", "content": f"<plan>\n{numbered}\n</plan>"}],            "calls": 1, "cost": call_cost(usage), "approved": {}}  def model(state):    """Call Claude, unless this question has used its limits."""    if state["calls"] >= agent.MAX_CALLS or state["cost"] >= agent.MAX_COST:        text = f"Stopped: this question reached its limit of {agent.MAX_CALLS} model calls or ${agent.MAX_COST}."        return {"messages": [{"role": "assistant", "content": [{"type": "text", "text": text}]}]}    response = agent.client.messages.create(        model=agent.MODEL, max_tokens=4000, system=agent.SYSTEM, tools=agent.TOOLS, messages=state["messages"],    )    content = [block.to_dict() for block in response.content]  # plain data, so the checkpoint can save it    return {"messages": [{"role": "assistant", "content": content}],            "calls": state["calls"] + 1, "cost": state["cost"] + call_cost(response.usage)}  def approve(state):    """Pause the graph for a yes or no on every call that changes something."""    decisions = {}    for block in state["messages"][-1]["content"]:        if block["type"] == "tool_use" and block["name"] in agent.NEEDS_APPROVAL:            decisions[block["id"]] = interrupt({"tool": block["name"], "input": block["input"]})    return {"approved": decisions}  def tools(state):    """Run every tool the model asked for and send all the results back together."""    results = []    for block in state["messages"][-1]["content"]:        if block["type"] == "tool_use":            print(f"  -> {block['name']}({json.dumps(block['input'])})")            decision = state["approved"].get(block["id"], False)            text, failed = agent.run_tool(block["name"], block["input"], lambda name, args: decision)            results.append({"type": "tool_result", "tool_use_id": block["id"], "content": text, "is_error": failed})    return {"messages": [{"role": "user", "content": results}]}  def next_step(state):    """After the model: run tools if it asked for any, otherwise finish."""    asked = any(block["type"] == "tool_use" for block in state["messages"][-1]["content"])    return "approve" if asked else END  builder = StateGraph(State)builder.add_node("plan", plan)builder.add_node("model", model)builder.add_node("approve", approve)builder.add_node("tools", tools)builder.add_edge(START, "plan")builder.add_edge("plan", "model")builder.add_conditional_edges("model", next_step, ["approve", END])builder.add_edge("approve", "tools")builder.add_edge("tools", "model")graph = builder.compile(checkpointer=InMemorySaver())  # saves the state after every step  def ask(question, config):    result = graph.invoke({"messages": [{"role": "user", "content": question}]}, config)    while "__interrupt__" in result:  # the graph paused for approval: ask, then resume it        request = result["__interrupt__"][0].value        yes = agent.ask_to_approve(request["tool"], request["input"])        result = graph.invoke(Command(resume=yes), config)    answer = "".join(block["text"] for block in result["messages"][-1]["content"] if block["type"] == "text")    print(f"  [{result['calls']} model calls, ${result['cost']:.5f}]\n")    print(answer)    return answer  def main():    config = {"configurable": {"thread_id": "terminal"}}  # one conversation, remembered by the checkpointer    print("Ask a research question. Type quit to stop.")    while True:        question = input("\nYou: ").strip()        if question.lower() in ("quit", "exit"):            break        if question:            ask(question, config)  if __name__ == "__main__":    if sys.argv[1:] == ["--draw"]:        print(graph.get_graph().draw_mermaid())    else:        main()
          • State is everything the graph tracks. Annotated[list, operator.add] tells LangGraph to add each step's messages to the list rather than replace it.
          • Each node is a function that takes the state and returns the parts it changes.
          • approve calls : the graph stops, ask gets your answer, and Command(resume=yes) carries on from that exact point.
          • InMemorySaver is the : it saves the state after every step under a thread_id, which is also how the graph remembers earlier questions.

        Learn from others
        
    
        3 common agent-building mistakes
        
  
        
  
        
    
        1
        An agent where a workflow would do
        
      
        What it looks like
        Five model calls to do what two fixed steps could, with more ways to go wrong and harder testing.
        
      
        Fix
        Write the steps down if you can. Use an agent only for the open-ended part.
        
    
        2
        Limits checked too late, or not at all
        
      
        What it looks like
        A run that loops on a failing tool and spends dollars before anyone notices.
        
      
        Fix
        Check call and cost limits before every model call, refuse repeats, and log each step (E8 adds traces).
        
    
        3
        Approval in the prompt, not the code
        
      
        What it looks like
        "Always ask before saving" in the system prompt, and nothing in the code that enforces it.
        
      
        Fix
        Enforce approval where the tool runs. Prompts guide the model; code decides what actually happens.
